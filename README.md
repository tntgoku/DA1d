
> 🔥 Lưu ý quan trọng:  
> Khi push code lên repository, **chỉ được push những gì nằm trong thư mục `src/`**.  
> Các thư mục và file sau **tuyệt đối không được push**:
>
> - `node_modules/`
> - `dist/`
> - `.vscode/`
> - `/public`
> - Các file log (`*.log`)
> - File cấu hình riêng tư (VD: `.local`, `*.suo`, `*.ntvs*`, `*.njsproj`, ...)
>
> ✅ Mọi người chỉ cần làm việc trong `src/`, còn lại đã được `.gitignore` cấu hình sẵn.
